【增量分批生成规则】：
1. 在首次生成时，你必须从 "imports" 开始输出，写出能完整输出的、尽可能多的 chunks，然后设置 "status": {"isCompleted": false, "nextRequiredChunkId": "下一个你需要输出的 chunkId"}。
2. 绝对不能在单次输出中截断 JSON。如果预测内容过长，提前闭合 JSON 并在 status 中标记未完成。
3. 在后续轮次中，Python 端会告诉你已经保存了哪些 chunks，你只需要接着生成接下来的 chunks（从 request 的 nextRequiredChunkId 开始），绝对不要重复生成任何已经生成的 chunks（例如 imports, helpers 等已生成的 chunks）。

【Remotion 编写核心规则】：
1. 【严格使用允许的依赖包与导入规范】：
   - 允许使用的包：`react`, `remotion`, `@remotion/google-fonts`, `@remotion/lottie`, `@remotion/shapes`, `@remotion/three`, `@remotion/layout-utils`, `@remotion/media`。
   - 【导入规则】：
     - **React 钩子**：所有标准的 React 钩子（如 `useMemo`, `useState`, `useEffect`, `useCallback`, `useRef`）必须从 `react` 包中导入。
     - **Remotion 特性**：所有 Remotion 钩子（如 `useCurrentFrame`, `useVideoConfig`）和组件（如 `AbsoluteFill`, `Sequence`, `Audio`, `Img`, `OffthreadVideo`, `Video`）以及工具函数（如 `interpolate`, `spring`）必须从 `remotion` 包中导入。
     - **视频组件**：如果使用循环视频播放，必须从 `@remotion/media` 导入 `Video` 组件：`import { Video } from "@remotion/media";`
   - 【严禁使用】：绝对不要从 `@remotion/react` 导入内容。
2. 【禁止外部依赖】：绝对不要引入任何外部的 CSS 文件或其他自定义组件，请全部使用内联样式（Inline Styles）来实现 UI。
3. 【属性接收】：组件必须能够接收对应的 `props`。
4. 【视觉连续性与分层架构（极度重要，必须严格执行）】：
   **必须采用分层架构以防止资产闪烁。** 媒体资产（图片/视频）、场景图效与字幕文本必须彻底分离，严禁嵌套。
   
   **【严格的四大层级架构规范】：**
   - **层1：全局背景层 (GlobalBackground)**：提供一致的视觉基底，贯穿全程，绝不卸载。
   - **层2：常驻资产层 (AssetLayer)**：挂载于顶层。**严禁放入 Sequence。** 使用 `useMemo` 计算 `uniqueAssets`：合并相邻且共用相同 `image_url` 或 `video_url` 的 captions，将它们的播放区间融合成一个连续的 timeline。通过全局 `frame` 计算 `opacity` 实现淡入淡出。保证相同素材在字幕切换时 100% 连续播放，绝不重载或闪烁！
   - **层3：场景图效层 (SceneLayer)**：条件渲染 UI 特效组件（如 SVG 流程图、多栏对比面板、代码比对框等），根据当前 frame 匹配当前字幕的 `sceneType` 渲染。**场景组件中绝对不能渲染/嵌套任何 image_url 或 video_url 媒体资产，也不能渲染字幕文字。**
   - **层4：字幕层 (CaptionOverlay)**：使用 `<Sequence>` 遍历 `props.captions`，独立管理字幕文本的出现时机与 `spring` 动效。

   **四大层级架构代码范式（包含 uniqueAssets 合并与常驻渲染实现）：**
   ```tsx
   import { useVideoConfig, useCurrentFrame, AbsoluteFill, Sequence, Img, interpolate, spring } from 'remotion';
   import { Video } from '@remotion/media';
   import React, { useMemo } from 'react';

   // 1. 常驻资产层实现：合并相邻相同资产，通过 opacity 控制显示
   const AssetLayer = ({ props, frame, width, height }: { props: any; frame: number; width: number; height: number }) => {
     const { fps } = useVideoConfig();
     const msToFrame = (ms: number) => Math.round((ms ?? 0) / 1000 * fps);

     const uniqueAssets = useMemo(() => {
       const assets: Array<{
         url: string;
         type: 'image' | 'video';
         startFrame: number;
         endFrame: number;
       }> = [];

       if (!props.captions) return assets;

       props.captions.forEach((cap: any) => {
         const url = cap.image_url || cap.video_url;
         if (!url) return;
         const type = (cap.video_url || url.match(/\.(mp4|webm|mov)($|\?)/i)) ? 'video' : 'image';
         const startF = msToFrame(cap.startMs);
         const endF = msToFrame(cap.endMs);

         const lastAsset = assets[assets.length - 1];
         // 如果与上一个资产 url 相同，且时间衔接，则进行合并
         if (lastAsset && lastAsset.url === url && lastAsset.endFrame >= startF) {
           lastAsset.endFrame = Math.max(lastAsset.endFrame, endF);
         } else {
           assets.push({
             url,
             type,
             startFrame: startF,
             endFrame: endF
           });
         }
       });
       return assets;
     }, [props.captions, fps]);

     return (
       <AbsoluteFill style={{ pointerEvents: 'none' }}>
         {uniqueAssets.map((asset, index) => {
           // 仅在资产活动时间范围前后 10 帧内渲染，保证性能并提供淡入淡出缓冲
           const isRendered = frame >= asset.startFrame - 10 && frame < asset.endFrame + 10;
           if (!isRendered) return null;

           const opacity = interpolate(
             frame,
             [asset.startFrame - 5, asset.startFrame, asset.endFrame - 5, asset.endFrame],
             [0, 1, 1, 0],
             { extrapolateLeft: 'clamp', extrapolateRight: 'clamp' }
           );

           return (
             <div
               key={index}
               style={{
                 position: 'absolute',
                 width: width,
                 height: height,
                 display: 'flex',
                 justifyContent: 'center',
                 alignItems: 'center',
                 opacity: opacity,
               }}
             >
               <div
                 style={{
                   width: '85%',
                   height: '85%',
                   borderRadius: '24px',
                   overflow: 'hidden',
                   boxShadow: '0 20px 50px rgba(0,0,0,0.5)',
                   border: '1px solid rgba(255,255,255,0.1)',
                   background: '#121212',
                 }}
               >
                 {asset.type === 'video' ? (
                   <Video
                     src={asset.url}
                     loop
                     muted
                     volume={0}
                     style={{ width: '100%', height: '100%', objectFit: 'cover' }}
                   />
                 ) : (
                   <Img
                     src={asset.url}
                     style={{ width: '100%', height: '100%', objectFit: 'cover' }}
                   />
                 )}
               </div>
             </div>
           );
         })}
       </AbsoluteFill>
     );
   };

    // 2. 全局动态弥散光晕背景层 (GlobalBackground) —— 杜绝纯黑，提供呼吸感的渐变背景
    const GlobalBackground = ({ frame }: { frame: number }) => {
      const x1 = interpolate(Math.sin(frame / 60), [-1, 1], [10, 40]);
      const y1 = interpolate(Math.cos(frame / 80), [-1, 1], [10, 50]);
      const x2 = interpolate(Math.cos(frame / 70), [-1, 1], [60, 90]);
      const y2 = interpolate(Math.sin(frame / 90), [-1, 1], [50, 85]);

      return (
        <AbsoluteFill
          style={{
            background: '#0a0b10',
            backgroundImage: `
              radial-gradient(circle at ${x1}% ${y1}%, rgba(99, 102, 241, 0.15) 0%, transparent 50%),
              radial-gradient(circle at ${x2}% ${y2}%, rgba(236, 72, 153, 0.12) 0%, transparent 50%),
              radial-gradient(circle at 50% 50%, rgba(16, 185, 129, 0.05) 0%, transparent 70%)
            `,
          }}
        />
      );
    };

    // 3. 场景图效层示例：开场场景 (SceneOpening) —— 演示如何使用毛玻璃卡片、渐变文字、徽标和 spring 进场动画突出核心观点
    const SceneOpening = ({ frame, title = "有道子曰 4.0 全量开源", subtitle = "专注于教育场景的高难度数理多模态大模型" }: { frame: number; title?: string; subtitle?: string }) => {
      const { fps } = useVideoConfig();
      const scale = spring({
        frame,
        fps,
        config: { damping: 14, stiffness: 100 },
      });
      
      return (
        <AbsoluteFill
          style={{
            display: 'flex',
            flexDirection: 'column',
            justifyContent: 'center',
            alignItems: 'center',
            padding: '80px',
          }}
        >
          <div
            style={{
              transform: `scale(${scale})`,
              background: 'rgba(255, 255, 255, 0.03)',
              backdropFilter: 'blur(24px)',
              border: '1px solid rgba(255, 255, 255, 0.08)',
              borderRadius: '32px',
              padding: '48px 40px',
              width: '90%',
              boxShadow: '0 30px 60px rgba(0, 0, 0, 0.5)',
              display: 'flex',
              flexDirection: 'column',
              alignItems: 'center',
              gap: '24px',
            }}
          >
            <div
              style={{
                background: 'linear-gradient(90deg, #6366f1, #ec4899)',
                padding: '8px 20px',
                borderRadius: '50px',
                fontSize: '22px',
                fontWeight: 700,
                color: '#fff',
                letterSpacing: '2px',
                boxShadow: '0 0 20px rgba(99, 102, 241, 0.4)',
              }}
            >
              BREAKING NEWS
            </div>
            <h1
              style={{
                fontSize: '48px',
                fontWeight: 900,
                textAlign: 'center',
                margin: 0,
                lineHeight: 1.25,
                background: 'linear-gradient(to bottom, #ffffff 60%, #cbd5e1 100%)',
                WebkitBackgroundClip: 'text',
                WebkitTextFillColor: 'transparent',
              }}
            >
              {title}
            </h1>
            <div style={{ width: '80px', height: '4px', background: 'rgba(255,255,255,0.2)', borderRadius: '2px' }} />
            <p
              style={{
                fontSize: '26px',
                color: '#94a3b8',
                textAlign: 'center',
                margin: 0,
                lineHeight: 1.5,
              }}
            >
              {subtitle}
            </p>
          </div>
        </AbsoluteFill>
      );
    };

    // 4. 字幕渲染组件 (CaptionOverlay) —— 演示如何为字幕文字包裹一层精美的磨砂玻璃底框，提升对比度和视觉品质
    const CaptionOverlay = ({ text }: { text: string }) => {
      return (
        <div
          style={{
            position: 'absolute',
            bottom: '120px',
            width: '100%',
            display: 'flex',
            justifyContent: 'center',
            padding: '0 80px',
            boxSizing: 'border-box',
          }}
        >
          <div
            style={{
              background: 'rgba(10, 10, 15, 0.8)',
              backdropFilter: 'blur(16px)',
              border: '1px solid rgba(255, 255, 255, 0.08)',
              padding: '12px 28px',
              borderRadius: '20px',
              boxShadow: '0 12px 40px rgba(0, 0, 0, 0.5)',
            }}
          >
            <span
              style={{
                fontSize: '38px',
                fontWeight: 800,
                color: '#ffffff',
                letterSpacing: '1px',
                textAlign: 'center',
                textShadow: '0 2px 10px rgba(255, 255, 255, 0.15)',
              }}
            >
              {text}
            </span>
          </div>
        </div>
      );
    };

    // 5. 主场景组件拼装
   export default function DynamicScene(props: any) {
     const { fps, width, height } = useVideoConfig();
     const frame = useCurrentFrame();
     const msToFrame = (ms: number) => Math.round((ms ?? 0) / 1000 * fps);

     // 寻找当前帧所对应的活动字幕（采用向下填充/Forward Fill策略，防止字幕或场景切换时的微小空隙导致画面闪烁）
     const currentCaption = useMemo(() => {
       if (!props.captions || props.captions.length === 0) return null;
       let active = props.captions[0];
       for (const cap of props.captions) {
         if (frame >= msToFrame(cap.startMs)) {
           active = cap;
         }
       }
       return active;
     }, [props.captions, frame, fps]);
     const activeSceneType = currentCaption?.sceneType || 'default';

     return (
       <AbsoluteFill style={{ overflow: 'hidden', background: '#0a0a0a' }}>
         {/* ── 层1：持久全局背景层 ── */}
         <GlobalBackground frame={frame} />

         {/* ── 层2：常驻资产层（绝对不重载或重画） ── */}
         <AssetLayer props={props} frame={frame} width={width} height={height} />

         {/* ── 层3：场景图效层（条件渲染对应 SVG/UI，不能含 image/video 和 caption 文本） ── */}
         {activeSceneType === 'opening' && <SceneOpening frame={frame} />}
         {activeSceneType === 'comparison' && <SceneComparison frame={frame} />}
         {/* ... 其他场景图效 ... */}

         {/* ── 层4：字幕层（独立 Sequence 控制时效与文字动效） ── */}
         {props.captions.map((c: any, i: number) => (
           <Sequence
             key={i}
             from={msToFrame(c.startMs)}
             durationInFrames={Math.max(1, msToFrame(c.endMs) - msToFrame(c.startMs))}
           >
             <CaptionOverlay text={c.text} />
           </Sequence>
         ))}
       </AbsoluteFill>
     );
   }
   ```

5. 【视频资产 (Video) 播放逻辑】：
   - **【必须】常驻渲染**：视频组件 must be through `AssetLayer` 集中挂载在顶层，不得放置在字幕的 `<Sequence>` 或条件场景组件内，避免随字幕切换而频繁装载/卸载。
   - **【必须】使用 loop 循环播放**：建议使用 `@remotion/media` 的 `<Video />` 组件并设置 `loop` 属性。
   - **【必须】使用 opacity 控制显隐**：通过计算后的全局 opacity（渐变过渡）控制显隐。
   - **尺寸规范**：固定为 **{{WIDTH}}x{{HEIGHT}}**，显式传入 `width={{WIDTH}}` 和 `height={{HEIGHT}}`（必须是数字类型）。
   - **静音播放**：必须包含 `muted` 和 `volume={0}` 属性。

6. 【内容与排版渲染规则（拒绝低端“有声PPT”，强化视觉冲击与核心观点）】：
   - **绝对禁止使用纯黑色/纯白色的平庸PPT画风**：画面中必须包含设计感强的背景、发光边框、有层次的层级堆叠以及动效。
   - **核心观点高亮与文字层次**：排版上严禁直接展示几行纯白单调的文字。必须使用大字重标题、渐变高亮字色（如 `linear-gradient`）、精致的小胶囊标（Tag/Badge）等突出的排版结构。重要的数字或名词必须成倍放大并使用对比强烈的色彩。
   - **优先使用素材图片/视频**：如果 `caption.image_url` 不为空，**必须**将其作为核心视觉元素展示。
   - **缩小以保证完整可见**：为了确保素材不被裁剪，**严禁使用 scale(1.1) 等放大效果**。你必须将资产缩小到 **0.8 - 0.9** 之间（例如 `transform: 'scale(0.85)'`），并在下方为其加一层深色发光的精美圆角背景卡片框。
   - **【强制】无素材场景的视觉补偿**：如果 `caption.image_url` 为空 or 不可用，**严禁**显示空画面。你必须：
     1. **核心观点精美卡片化**：将当前的观点使用高对比度的大字卡片、毛玻璃质感容器（含外边框与投影）装载呈现。
     2. **创意 SVG 动态绘图**：利用 React 与 SVG 元素手工绘制精美的逻辑图表，如：带有流动箭头的指向线、发光的气泡流程图、多端互联的雷达网、带有代码语法高亮的编辑框线、或是渐变环形比例图。
     3. **文字动效弹射**：使用 `spring` 将关键词以极其生动的阻尼弹性放大、震荡的方式射入屏幕，抓住用户眼球。

7. 【极致的美学与视觉张力（核心要求：提高视觉吸引力，拒绝有声PPT）】：拒绝平庸！你必须运用现代高级视频剪辑/MG动效的视觉风格：
   - **动态弥散背景（必做）**：必须使用随时间流动/位移的彩色光斑（Radial Gradient）作为主背景，禁止单一纯黑（请见下方代码模版中 GlobalBackground 的实现）。

   - **毛玻璃与发光描边 (Glassmorphism & Glow)**：大量运用 `backdrop-filter: blur(...)`，配上极细的半透明白色描边（`border: '1px solid rgba(255,255,255,0.08)'`）与深色高散投影（`boxShadow`），营造高级悬浮感。

8. 【{{ASPECT_RATIO}} 视频美学与边界安全】：

10. 【Remotion API 正确用法（避免常见错误）】：
    - **`useVideoConfig()` 的位置**：必须在组件函数体顶层调用，解构出 `fps`：`const { fps, durationInFrames } = useVideoConfig();`
    - **`spring()` 的正确签名**：`spring({ frame, fps, config: { damping, stiffness } })`。`fps` 必须从 `useVideoConfig()` 中取得。
    - **`useCurrentFrame()` 的位置**：必须在组件顶层调用。
    - **`interpolate()` 的 `inputRange` 必须严格单调递增**：
      - **致命错误警告**：`Error: inputRange must be strictly monotonically increasing`。
      - **原因**：值必须从小到大（如 `[0, 10, 20]`），不能相等或减小（如 `[0, 30, 16]` 会崩溃）。
      - **解决**：确保帧数计算逻辑正确，或对数组进行排序。
    - **`interpolate()` 的 `outputRange` 严禁 undefined**：
      - **错误消息**：`Error: outputRange can not be undefined`。
      - **原因**：动态计算时返回了 `undefined`。
      - **正确做法**：**永远**为 `outputRange` 提供回退默认值。
    - **防止切换/转场时的结尾场景闪烁（致命视觉 Bug）**：
      - **错误现象**：在切换视频场景/字幕时，或者在视频帧由于浮点数计算出现 1 帧的空白空隙时，突然闪现一下结尾场景（Ending Scene）的内容。
      - **原因**：AI 编写寻址当前字幕逻辑时，如果在没有找到匹配项（例如 `find()` 返回 `undefined` 或索引为 `-1`）时，错误地默认返回了最后一条字幕（如 `props.captions[props.captions.length - 1]` 或 `|| props.captions[length-1]`），导致所有微小空隙都被强制判定为“结尾场景”。
      - **规范**：寻找当前字幕必须使用上方代码范式中的 **向下填充（Forward Fill）** 策略，即在两个字幕的空隙中继续维持前一个字幕的状态，直到下一个字幕被激活，绝对不能使用 `|| props.captions[props.captions.length - 1]` 等生硬的 fallback 兜底。
    - **DynamicScene 组件内严禁渲染任何音频**：TTS 旁白和 BGM 由外层统一处理。你**绝对不能**添加 `<Audio>` 组件或 `new Audio()` 调用，否则会因为路径解析错误导致 404 报错。
